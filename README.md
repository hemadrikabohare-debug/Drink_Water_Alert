# 💧 Drink Water Alert

A simple Python desktop application that reminds users to drink water at regular intervals using desktop notifications and sound alerts. The application provides an easy-to-use graphical user interface (GUI) built with Tkinter to help users stay hydrated throughout the day.

## 🚀 Features

- 🔔 Desktop notifications for water reminders
- 🔊 Sound alerts using a WAV file
- 🖥️ Simple Tkinter-based GUI
- ▶️ Start and stop alerts anytime
- ⚡ Lightweight and beginner-friendly project

## 🛠️ Technologies Used

- Python 3
- Tkinter
- Plyer
- Winsound
- Threading
- Time Module

## 🔔 How It Works

1. Click **Start Alert**.
2. The application sends a desktop notification.
3. A sound alert (`water.wav`) is played.
4. Notifications repeat every 10 seconds.
5. Click **Stop Alert** to stop reminders.

## 💻 Interface

The application contains two buttons:

- **Start Alert** - Starts water reminders.
- **Stop Alert** - Stops water reminders.
